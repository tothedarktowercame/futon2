## The worked transformation: honest-holes-gate-composed-claims

Ostrom's IAD rule types, each mapped from the flexiarg's fields — and
the mapping is nearly mechanical, which is the finding:

| IAD rule | from flexiarg field | the institution's text |
|---|---|---|
| POSITION rule | @audience | Positions: compositor (emits a composition), publisher (makes it readable), reader (consumes the map). One agent may hold several positions. |
| BOUNDARY rule (entry) | + context | A composition ENTERS the regime when it aggregates >1 dimension of the record into a publishable claim (cascade, page, summary). |
| BOUNDARY rule (exit) | + THEN | A composition LEAVES the regime (is publishable) when it carries, per composed dimension, either the hole list or a typed none {:checked [...] :holes-found 0}. |
| CHOICE rule | IF / THEN | The compositor MAY publish at any time; it MUST NOT publish with an untyped-absent hole dimension. s4=true requires typed evidence, not empty set. |
| AGGREGATION rule | HOWEVER | Scope-limited census: the composition's OWN dimensions only (cost bound); collective-choice for widening scope is the Workshop's proposal channel. |
| INFORMATION rule | + THEN, rendered | The falsity must be rendered IN-BAND: publishing with s4=false is permitted only with the red lamp on the page itself (readers are information-rule participants, not externalities). |
| PAYOFF rule | + BECAUSE | Fogless maps degrade readers (three agents believed a dirty tree; monitors drift to "fine") — the payoff rule prices hidden gaps as debt the whole commons pays, not savings for the compositor. |
| SANCTION / monitoring | @status + NEXT-STEPS | Graduated: first instance is a named counterexample carried ON the pattern itself (already true: s4=false is recorded there); repeated untyped publication is a register disagreement (verifier's channel); the standard going true on untyped emptiness is the boundary violation (falsifying s4's evidence class). Monitored by the verifier (N1) — the institution's police is an existing crew member, not a new one. |

## What the experiment shows

1. **The flexiarg was already carrying the institution's parts.**
   context→boundary, IF/THEN→choice, HOWEVER→aggregation (cost-bounded
   scope), BECAUSE→payoff rationale, NEXT-STEPS→monitoring. The
   transformation is interpretive WORK (naming positions, graduating
   sanctions) but not invention — the normative content was in the
   pattern, distributed across its fields.
2. **What the institution adds the pattern lacked**: POSITIONS (who
   holds the duty — the pattern says "should", the institution says
   "the compositor must"), GRADUATED SANCTIONS (a pattern can be
   violated; an institution can be violated *repeatedly, with
   escalation*), and a named MONITOR (the verifier — Ostrom's
   "monitoring by participants" maps to the crew's existing N1).
3. **Circumstances of application** (Joe's earlier question) fall out
   as the boundary rules: the institution binds exactly when a
   composition enters the regime — an applicability predicate in IAD
   clothing.
4. **The deontic vocabulary is already in the runtime**: MUST-NOT
   publish untyped = a forbidden traversal (typed refusal on the wire);
   MUST carry none-or-holes = an obligation chip; MAY publish = the
   default. The meta-board of NOTE-pattern-interpretations.md has
   concrete first content.
5. **Applicability of the applicability**: s4=false live today means
   this institution is currently being VIOLATED by the page's
   substrate (not the page — it renders the falsity in-band, which is
   compliance with the information rule). The experiment's first
   finding is therefore a live one: O5's typed-none record is the
   institution's first compliance act. NEXT-STEPS names it.
