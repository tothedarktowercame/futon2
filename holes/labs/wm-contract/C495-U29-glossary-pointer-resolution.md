## 3. What the drift check could not see, and now can

Two checker gaps surfaced while correcting, both of the class S1 named — a
pointer can resolve and still be wrong.

**(a) Same-area drift read as green.** `pointer-status` compares the AREA of
the row with the area of the paragraph the cited line lands in, so a pointer
that slides onto a neighbouring paragraph of the same area reports
`:resolves`. `HaveWantArrowState` at `:70` landed on *Act-gate* — demo area,
demo row, green — while being about a different paragraph entirely; the same
held for `ParameterPriorKernel` at `:29` on *Ambiguity*. These were never in
the 22. They are corrected here, and the registry records `:resolved-title`
on every glossary row (it already did on drifted ones), so the paragraph a
pointer actually names is now readable in the file rather than only derivable.

**(b) The area table did not name five paragraphs.** `title-area` had no
branch for *Model uncertainty and EIG*, *Predictive outcome distribution*,
*Dirichlet concentration parameters*, *Log multivariate beta and $\Delta F$*
or *Bayes factor threshold*, so a declaration whose owner had drifted OFF one
of them onto a neighbour the table DID name read as resolving. Correcting the
pointers made this visible: `bayesFactorThreshold` pointed correctly at
*Bayes factor threshold* would have reported `:unclassified` and hence
drifted. The five titles are added
(`scripts/generate_variable_situation_accounting.bb`, `title-area`).

**(c) A new check: every cited line must be a paragraph's own line.** A
citation into a paragraph BODY survives a small insertion above it by sliding
onto the following paragraph's text while still matching on area — drift with
nothing to report it. All 47 glossary owners cite paragraph lines after this
row, so the check is satisfied by the corrected tree; a citation that is not
a paragraph start now reads `:drifted` with reason
`:cited-line-is-not-a-paragraph-start` and names the offending lines.

**(d) The zero is controlled.** `--negative-drift` plants both shapes against
the live glossary (a wrong-paragraph owner and a body-line owner) and requires
each to be rejected with its own reason; `p4ng/empirics-futon/negative_controls.sh`
control 1d runs it on every publish. Without it, "0 drifted" from a clean tree
and "0 drifted" from a checker that stopped seeing drift read the same.
