## The shape (transplanted from empirics)

The empirics pipeline's discipline, applied to WM runs:

```
runs/<run-id>/…                          (the run store: traces, gauges,
        │                                 rationales, conformance artifacts)
        ▼  per-check bb scripts           (each deposits one typed row)
run-era-ledger.edn                       (the seam — append-only, one row
        │                                 per (run-id, check-id), verdict +
        │                                 artifact pointer + at)
        ▼  extraction (later row)
generated chart/section                  (feeds Futon-2026 supplement and
                                          the PLoP revision — NOT built yet)
```

Disciplines inherited verbatim from the empirics model and this campaign:

- **Generated vs hand-maintained** declared per artifact; generated files
  stamped with source + time, never hand-edited.
- **Honest store rule**: a check reports what the run store holds; a run
  that deposited nothing appears as a typed absence, not a blank.
- **Time-correlation is the point**: every ledger row carries run-id and
  timestamp so verdicts form a series ("era flags" in the Field Desk
  chart's sense — pre-flip, per-flip, post-flip windows).
- **Append-only, fold-of-events** (the tension-ledger discipline; schema in
  file; validator green in the same commit as any append).
- **Bare gate exits** — no check piped through tail/grep before acting.
