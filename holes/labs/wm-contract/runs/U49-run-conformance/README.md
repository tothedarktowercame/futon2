## The comparison is RUN3's

`run3_conformance.bb` produced this run's pinned `:verdict :conformant`, so
`classifyHop` transcribes its decision rule clause for clause
(`run3_conformance.bb:116-124`): a hop is dispositioned by the SET of grounds
its pair was retired on before the drawn and measured layers are consulted.

That matters. **A flat "no retired edge traversed" would report s5 NOT
conformant.** s5 traverses `R2 → R7`, which is `:code`-retired but also on the
`:route-measured-drawn` layer, so run3 EXCLUDES it (a route is a sequence of tag
stamps, not the dependency DAG, so it cannot refute a dependency claim); and it
traverses `R5 → R6`, which is `:ruling`-retired, which run3 reports as *the
ruling is not realised in code* — a build row, not a conformance failure.
