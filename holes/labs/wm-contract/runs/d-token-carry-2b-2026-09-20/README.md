# Frozen D/Q receipt artifact

`schema.edn` is the machine-readable v1 contract. Its `:required`, `:absent`,
`:equalities` (pairs of receipt-relative key paths), enums and status rules
describe validation obligations, not executable predicates or production
admission. The full join prose is in `../../SCHEMA-d-belief-update-v1.md`.

`examples.edn` contains constructed instances for Q intake tests. Every entry
has `:receipt`, `:q0` when consumable, and `:expected-intake`. They are isolated
fixtures with no production enactment or observation authority. The exact
calculations are generated by the real finite adapter; the initializer comes
from the real fact-receipt producer. `build_examples.clj` generates and checks
them without calling a runner, observer, enactor, or shared JVM.

The six examples cover a licensed point-mass value, a nonvacuous distributed
value, both refusal channels, missing observation, and an invalid floating
point prior. The invalid fixture supplies a valid candidate q0 outside the
receipt so Q can demonstrate typed rejection rather than a shape accident.

`:consumed` has one narrow meaning: the received observation produced an
accepted exact posterior. It is true only for `:value`, false for refused,
missing and invalid. It does **not** mean that the continuation belief was
unused. On checkable refusal the observation supplies a separate, explicitly
recorded reinitialization; Q still consumes that continuation. The refusal
must remain visible and must never become a successful Bayes update.

The explicit license is `:vacuity-license`. `:licensed` carries the full Lean
theorem symbol, positive predicted `:support`, `:constant-likelihood` and
`:predicted-total`. The point-mass theorem requires singleton predicted
support, not singleton incoming support. A changing posterior is
`:not-licensed`; refused/missing/invalid are `:not-applicable`. Presence of a
theorem name alone does not establish its hypotheses. Q can check the stored
likelihoods and predicted belief and compute extensional vacuity without
reconditioning. Non-licensed receipts must not carry a theorem claim.

For checkable reinitialization, the example has a fully observed admitted
point state. Equality of that state, initialization `:value`, reinitialization
`:belief`, continuation and q0 is explicit. Partial observations cannot silently
turn unmeasured tokens into negative observations; the producer must establish
the initialization authority separately.

This artifact unblocks the Q interface. It does not resolve the production
enacted-predecessor gap recorded in
`../../D-2b-enacted-predecessor-discovery-2026-09-20.md`.
