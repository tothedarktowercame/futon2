# Host-origin trust boundary

The configured reader verifies the exact independently configured session path, one-based line, and newline-inclusive SHA-256 before considering origin. Verification additionally requires a separately byte-pinned `:wm/host-process-origin-review-v1` record whose accepted subject is exactly that source/line/hash and which names the root identity and delegate. The candidate supplies none of these paths or pins. At HEAD no such independent trust-review record exists for the located Joe events, so the actual read-only probe verifies the event bytes and then refuses `:r9/host-origin-review-missing`. This is not a claim that signatures are mandatory; the missing dependency is an independently reviewed explicit host-process/session-origin trust record.
