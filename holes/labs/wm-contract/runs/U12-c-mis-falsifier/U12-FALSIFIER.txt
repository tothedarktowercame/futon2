=== 5. CLAUSE (c): THE SATISFIED-CRITERIA ZERO ===

  §7 asks that risk_mis 'go to zero as criteria are met on a planted field where
  all criteria read satisfied'. Planted field: every planted observable at its
  {:becomes 1} target, built from the bindings so it cannot drift from them.
  The unsatisfied field is shown twice, once at the long 0 and once at the

    UNSATISFIED, double 0.0    ({:support-coverage 0.0, :mission-health 0.0, :annotation-health 0.0})  risk_mis = 4.539889921682063E-5
    the live observation of 801976e7                                   risk_mis = 4.539889921682063E-5

    zero? NO. The satisfied value is a FLOOR set by temperature alone,
    −ln c* where c* = 1/(1+e^(−1/T)) = 0.9999546021312976 at T = 0.1
    (preferences.clj:216-221). The literal zero needs T → 0.

    AND THE UNSATISFIED POLE IS NOT REACHABLE FROM THE MACHINE'S OWN
    OBSERVATION VOCABULARY: at the double 0.0 the same field scores 4.539889921682063E-5,
    identical to the satisfied field, for §4's reason. The 10.0 above needs a
    long or a boolean, and no R2 channel produces one. So the ratio below is
    what the two POLES are worth in principle, not a spread the live path can
    produce.

    A RANGE SPEC IS A DIFFERENT PROBLEM AND IT IS REACHABLE. For :spec [lo hi]
    the term is −ln C(x) = gap/T + ln Z, and inside the range that is ln Z,
    which is NEGATIVE for any range narrower than [0,1]:
      spec [0.0 1.0]    at x = 0.5     risk_mis = 0.0
      spec [0.5 1.0]    at x = 0.75    risk_mis = -0.5119492459595545
      spec [0.4 0.6]    at x = 0.5     risk_mis = -0.9254907419272016
      spec [0.8 1.0]    at x = 0.9     risk_mis = -1.2040846314543239

    No criterion in the corpus declares a range :spec, so this is reachable
    and unexercised rather than a live wrong number. It matters for U13
    because C_int's risk is a KL (≥ 0, preferences.clj:277-299) while
    risk_mis is a surprisal: summing them in one G would let a satisfied
    range criterion pay a BONUS, which is not what a cost term may do.

    Satisfied is 4.539889921682063E-5, not 0 -- that part is a temperature floor and would
