# C537 — Serendipity shapes C: preferences before goals (F10 input)

Operator guidance, Joe, 2026-09-06 (paraphrase kept close): C is a matter of
PREFERENCES, not necessarily goal outcomes. The serendipity model
(Corneli, Jordanous, Guckelsberger, Pease & Colton, arXiv:1411.0440) has a
GOAL FORMATION phase: drip irrigation was invented by seeing an
exceptionally large tree and realising a leaky pipe was dripping on it —
"identification of a question" ("how is this tree so large?"); "turning it
into a product only happened much later." If we include the serendipity
model, "we're going to have discovery of interesting potential applications
BEFORE we have goals or outcomes that we could apply them to."

This note is F10 input (the C definitional slice), not a ruling.

## 1. The model, pinned

arXiv:1411.0440 gives six phases: **perception → attention → interest →
explanation → bridge → valuation**, serendipity as "a creative process that
develops, in context, with the active participation of a creative agent,
but not entirely within that agent's control," and the design claim that
SERENDIPITY POTENTIAL can be raised architecturally. "Serendipity is not
teleologically blind."

## 2. What this does to the C question

The belly precedent (C533) gave C's outcome domain as GOAL-STATES: the
goal-outcome half derived preference entries from the formed-goal corpus.
Joe's point: that covers only the POST-formation side — valuation of
progress on goals that already exist. Phases 1–4 of the serendipity model
(perception, attention, interest, explanation) happen BEFORE a goal
exists. The drip-irrigation tree was preferred — dwelt on, attended,
explained — years before any goal it served.

So the F10 outcome domain must be wide enough to carry preference mass on
PRE-GOAL outcome kinds: question-identified events, anomaly-accommodated
events, interesting-potential observations. A C typed only over
goal-advancement can never prefer to dwell on an anomaly that serves no
current goal — serendipity potential would be architecturally EXCLUDED by
the type, which is the exact opposite of the paper's design claim.

## 3. Division of labour inside G (why this is C's job, not EIG's)

The epistemic leg (EIG) rewards expected information gain UNDER THE
CURRENT MODEL — curiosity about known unknowns. The standing conjecture
`p4ng/NOTE-bridge-as-surprisal.md` already maps the Bridge to
structure-changing surprisal (structure learning, not belief updating) and
notes the bridge is definitionally ABSENT FROM THE MENU (WR-19): no
ranking signal reaches it. What CAN be architectural is preference for
the BANKS — observation-states that are occasions for bridges ("enumerate
the banks and build the occasions"). That is preference-side, pragmatic-
leg content: C putting mass on being-in-interesting-territory. Hence:

- **C_int** — channel floor (live; health grain).
- **C_mis** — goal-outcome half (the belly; built, currently dark, C533).
- **C_ser (proposed)** — preference mass on pre-goal interestingness:
  question-formation and structurally-surprising-but-accommodatable
  observation kinds. The serendipity phases give its vocabulary; the
  bridge note gives its discriminator (accommodation that generalises vs
  noise).

The F10 outcome-domain candidates list therefore grows by one:
question-formation events, alongside mission observation closure,
typed-absence vocabulary, grounded-change events, and the belly's
goal-states.

## 5. What this does NOT decide

note widens the domain candidates and records why, on operator guidance.
