## 2. Producer, observer, and silent fallback

The phase begins in `run-opportunity-core!` at `run-phase!`; its body calls
`selected-target-reading-step`, and a published reading immediately enters the
nested `:selected-target-reading-redecision` phase
(`full_loop_runner.clj:7472-7496`).  The step obtains `record` from
`repair-fn`; on success it attaches that record to the redecided judgment, but
if redecision throws it seals the sidecar and no successful step result exists
(`full_loop_runner.clj:2427-2449`).  The live wrapper likewise seals the record
and rethrows (`full_loop_runner.clj:7497-7508`).

The terminal observer is computed later by `persist-run-record!`:

```clojure
:selected-target-reading (retained-selected-target-reading result)
:reading-frontiers (retained-reading-frontiers result outer-task-selection)
```

(`full_loop_runner.clj:1436-1438`).  `retained-reading-frontiers` calls the same
observer and projects its preparation fields (`full_loop_runner.clj:1202-1241`).
On failed redecision the selection checkpoint has only a not-reached `:sorry`,
not the request (`DEFECTS-reading-era.md:2274-2281`).  Both checkpoint lookups
therefore miss and lines 1199-1200 silently manufacture:

```clojure
{:status :not-applicable
 :reason :selected-target-reading-not-required}
```

The core-local result is ultimately passed to `persist-run-record!` with
`raw-opts` (`full_loop_runner.clj:9205-9210,9320-9326`), but no reading state is
currently among the shared atoms created in `run-opportunity!`
(`full_loop_runner.clj:9180-9196`).

## 4. Smallest correction

Add one shared per-run atom, initially explicitly `:not-started`.  Have
`selected-target-reading-step` mark it started before `repair-fn` and store the
exact returned record before redecision.  Make
`retained-selected-target-reading` read this state first: return the record
when present; if started without a result, return a typed absence naming that
failure.  Only explicit `:not-started` may produce not-required.  A checkpoint
with no request and no conclusive phase state must instead produce the R28
typed absence `{:status :absent :reason
:selection-checkpoint-without-request}` (`DEFECTS-reading-era.md:2282-2291`).
Pass that same observation into `retained-reading-frontiers`, so both fields
describe the one retained event.  This changes no reading or redecision policy.

The discriminating offline test should replay the failed checkpoint/result
with a retained record and assert that both observer fields contain its actual
`:records` and `:pending`; it should separately assert that started-without-
result is absent and only not-started is not-required.
