# Deposit templates

`T-addressed/` is an offline mechanics template, not acquired authority.
Before a live attempt, replace every `__REPLACE_...__`, every `TEMPLATE:`
command, the review-grade explanation, and applicable timestamps with the
actual attempt's values and recapture their literal output bytes.
`subject-before.edn` is the immutable finding; `subject-after.edn` is a
`repair-derived-state` readback, not another finding copy.
