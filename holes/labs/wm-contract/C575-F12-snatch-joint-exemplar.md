# C575 — F12 snatch joint exemplar

The existing `find-organise` implementation constructs six CascadeDiff rows, one for each treatment/disposition pair, by grouping the twelve snatch scenarios and using the `:patterns` policy row as “before” and `:exchange-first` as “after” ([find_organise.clj:603-633](../../../futon3/checks/find_organise.clj)). The executable checker resolves `cascade-diff-table`, `organise-laws`, and `organise-reproduces-record?` from that namespace rather than spelling organise, fast-forward, or O4 again ([f12_snatch_joint_check.bb:24-40](../f12_snatch_joint_check.bb)).

All six computed rows carry at least one organised edge and moved precedence on the same row; all six also move acting order and pass the namespace’s own O4 predicate ([23-snatch-joint.edn:1-152](runs/F12-organise/23-snatch-joint.edn)). The score moves only for `[:g4 :snatcher]`; its recorded values are 3 before and -5 after ([snatch-cascade.edn:84](../../../futon3/checks/snatch-cascade.edn), [snatch-cascade.edn:211](../../../futon3/checks/snatch-cascade.edn)).

This is a re-wiring comparison over one recorded collection, not two independently constructed cascades. The resulting edges come from organising the `:patterns` row’s acting set. The `:exchange-first` row supplies only after precedence, acting order, and score in `cascade-diff-table` ([find_organise.clj:616-633](../../../futon3/checks/find_organise.clj)); its own recorded `:nodes` collection has one node ([snatch-cascade.edn:210](../../../futon3/checks/snatch-cascade.edn)).

The earlier census did not contradict this result. Its declared snatch input is the raw `checks/snatch-cascade.edn` record with edge mode `:none`, rather than the derived CascadeDiff table ([f12_o4_edges_census.bb:8-22](../f12_o4_edges_census.bb)). Consequently its snatch entry reports O4 shape absent, no before/after pair, no per-run cascade-edge paths, and `:carries-both? false` ([20-o4-edges-census.edn:238-249](runs/F12-organise/20-o4-edges-census.edn)). The checker reads those values and key paths from the old artifact into `:census-gap`; it does not reinterpret or edit that scoped census ([f12_snatch_joint_check.bb:67-80](../f12_snatch_joint_check.bb)).

Four mutations establish that the headline is actually checked: emptying an edge set, flattening one row’s precedence change, dropping a scenario, and repointing the prior-census pointer each make the verdict false ([f12_snatch_joint_check.bb:96-126](../f12_snatch_joint_check.bb)). Whether this derived joint exemplar also satisfies Joe’s separate item-4 evidentiary ruling is not decided here.
