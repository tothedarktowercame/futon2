## 2. Proposed layout (trialled)

The packet's premise — "the posterior imports the prefix module for F" — **has
a hole**: the prefix module imports `ObservationAtMachine` → `ActionAtMachine`
→ `PolicyPosteriorAtMachine`, so a posterior→prefix import is an import cycle.
Demonstrated against the generator (scratch `cyc/`): it refuses with
`import cycle: …​BeliefStepAtMachine -> ActionAtMachine ->
PolicyPosteriorAtMachine -> PrefixFreeEnergyAtMachine -> ObservationAtMachine
-> ActionAtMachine`. Breaking it the other way (moving the two
`machineObservationLaw` theorems out of the prefix module, then posterior
imports prefix) additionally **regresses [R2 R8]** (the prefix module no
longer reaches R2's only module) and **flips [R8 R3] to :imported**
(BeliefStepAtMachine → ActionAtMachine → posterior → prefix), which the
packet says to leave alone pending the ruling. Both are avoided by putting
the composition in a **sibling module**, the same lesson W10 recorded in
`:policy-posterior`'s `:lean-at` ("the application lives in the module that
holds the row's term" — here the row is new and holds it).

### Layout

1. **New module `Proof2/CascadePolicySet.lean`** — the P0 rebind of
   `:policy-set`. Receives **moved verbatim** from EnactmentHabit:
   `PolicyKey`, `KeyProvenance`, `KeyAbsence` (EnactmentHabit.lean:85–133).
   Adds the conformant carrier: `cascadePolicySet (menu : List (PolicyKey M
   P)) : Set (PolicyKey M P)` with `mem_cascadePolicySet`. Imports `Holes`
   only. (This is the reading of the plan's "a second R6 module **at**
   EnactmentHabit.PolicyKey": the key type moves to the module; see §3 for
   why that move and not a reference.)
   `EnactmentHabit.lean` loses those three declarations and gains
   `import`/`open … CascadePolicySet`. Every remaining habit declaration is
   statement-identical.
2. **New module `Proof2/PrefixFreeEnergyPosterior.lean`** — the [R8 R6]
   composition. Receives **moved verbatim** the whole `FPosterior` section of
   PrefixFreeEnergyAtMachine (:380–454): `PrefixWeightsAbsence`,
   `machineWeightsAtPrefixF`, `machineWeightsAtPrefixF_eq`,
   `notSuppliedIsAbsence`, `contradictionHasZeroWeight`. Imports
   `Proof2.PrefixFreeEnergyAtMachine` and `Proof2.PolicyPosteriorAtMachine`.

   PolicyPosteriorAtMachine` and the `FPosterior` section; swaps
