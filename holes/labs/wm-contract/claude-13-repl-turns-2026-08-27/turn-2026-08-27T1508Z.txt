**The one finding: `declaresCoverage` was vacuous.**

```lean
∀ outcome, criteria.covers outcome = true ∨ criteria.covers outcome = false
```

That's `∀ b : Bool, b = true ∨ b = false` — provable of *every* criterion set. Totality is already forced by the type `Outcome → Bool`, so there was nothing to state and the first conjunct of `coverageReported` was decoration. Same class as the three I found in `GainChain`: declared and not constrained.

Replaced with the content R5 actually asks for:

```lean
def declaresCoverage ... := ∃ outcome, criteria.covers outcome = false
```

**The set names at least one outcome it does not cover.** A criterion set covering everything has no boundary to report, and stating the boundary is the whole requirement — Klarna measured four real metrics at scale and none reported what they didn't cover. The nonvacuity proof's first goal correspondingly changed from an `intro` to *exhibiting the boundary*, which is the right shape.
