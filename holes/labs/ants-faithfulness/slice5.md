# Re-specified Slice 5: AIF term ablations

Status: complete.

## Frozen environment and protocol

The environment was copied verbatim from the causal-authority run before the first simulation and was not tuned afterward: `{:scenarios [:patchy :sparse :snowdrift], :size [10 10], :food {:patchy {:num-patches 4, :patch-radius 2}, :sparse {:num-patches 2, :patch-radius 1}, :snowdrift {:num-patches 4, :patch-radius 2}}, :ticks 300, :initial-reserves 0.5, :metabolism 0.06, :ants-per-side 3, :arms [:aif-full :no-canonical-ambiguity :no-directed-eig :no-info-gain :no-risk :classic]}`. Each cell has 30 independently seeded 300-tick runs; seed triples are shared across arms, and contrasts use paired two-sided 95% t intervals. Starvation is the explicit share of runs whose yield is exactly `0.0`.

Seeds are generated by `slice5-seeds`: for zero-based scenario index `s` and run index `i`, food=`202608110+100000s+2i`, movement=`202608111+100000s+2i`, and choice=`202658110+100000s+i`. Every concrete triple is logged in the raw EDN.
