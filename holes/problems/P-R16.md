**solved** (checked before the machine runs again):
1. **The registry replaces the fixture, and it is derived.** `GroundingRegistry := Mission → Option Witness`
   where membership is *derived* from a declared grounding relation (a mission is groundable iff a CLean path
   with a recorded producer exists for it — the relation is data, the set is computed), and a mission outside
   it yields the **typed absence** `:no-grounding-for-mission`, never `nil`/`0` (GainChain's `typedAbsence`).
   **Falsifier:** `bayesian-structure-learning` is outside today; the checker must return the typed absence for
   it, and a fifth mission added to the relation must be groundable *without editing a map* (I1 gets its
   refusing and accepting witnesses).
2. **An actuation is a witness outside the model.** `Actuation := {mission, act, witness : ExternalWitness}` where
   `ExternalWitness` is a record in a substrate the generative model does not write (a commit sha, a file
   digest, a substrate-1 artefact), and `R16→R2`'s payload IS that witness — the `Delivery` schema for the
   re-observe edge is `{tick, mission, witness}`; a tick whose observation vector does not read it is the ring.
   **Falsifier:** an "enactment" whose only witness is the enactor's own coverage-ΔG over its own diagram must
   be refused as re-observation (the pattern's HOWEVER, as a predicate).
3. **The act-gate as the glossary states it**, as a body: `actGate (S_cascade ΔS_coverage : Option ℝ) : Decision`
   — `act` iff both present ∧ `S_cascade > 0` ∧ `ΔS_coverage < 0`; `abstain` if either absent; never F or G.
   **Falsifier:** the glossary's own example (`+1.2`, `−0.8` passes; a positive coverage delta fails).

**facades:** a fixture as a domain ("live-CAPABLE" over four entries); `:enacted nil` folded into a score of
0; re-observation of the model's output presented as the world changing; a whitelist edited to admit a fifth
mission (I1 violated by hand); an act-gate that guesses when a leg is absent; the act-gate reported as G.

**status.** open.
